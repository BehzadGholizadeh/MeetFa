# تست دستی — دریافت پیوسته زیرنویس (Stage 2.1)

پیش‌نیاز: `npm ci && npm run build` → `chrome://extensions` → Reload افزونه → **refresh تب Meet** (بعد از هر Reload افزونه الزامی است).

| # | اقدام | انتظار |
|---|---|---|
| 1 | ورود به جلسه، CC روشن، Side Panel باز | «آماده» + «زیرنویس روشن است؛ منتظر صحبت…» |
| 2 | ۲۰ ثانیه صحبت پیوسته | «در حال دریافت»؛ متن هم‌زمان با Meet رشد کند |
| 3 | **۱۰ ثانیه سکوت**، سپس ادامه صحبت (همان گوینده) | در سکوت: «آماده»؛ بعد از ادامه: متن تازه در پنل ظاهر شود (بخش جدید زیر بخش قبلی) |
| 4 | مرحله ۳ را ۵ بار تکرار کنید | هر بار متن تازه ثبت شود؛ بدون تکرار جمله‌های قبلی |
| 5 | صحبت طولانی ۲ دقیقه بدون مکث | متن قطع نشود؛ ابتدای جمله‌ها حذف نشود |
| 6 | نفر دوم صحبت کند | بخش جدید با نام گوینده دوم |
| 7 | CC را خاموش و دوباره روشن کنید، سپس صحبت | دریافت ادامه یابد |
| 8 | زیر «آخرین متن دریافتی» | ساعت با هر متن تازه جلو برود |
| 9 | اگر وضعیت «خطا: متن زیرنویس Meet تغییر می‌کند ولی در MeetFa ثبت نمی‌شود» دیده شد | باگ باقی‌مانده؛ مرحله ۱۰ را اجرا و نتیجه را گزارش کنید |
| 10 | عیب‌یابی: F12 روی تب Meet → Console → فهرست context را روی MeetFa بگذارید → Verbose را فعال کنید | لاگ‌های `[MeetFa] status …` و `caption region attached/detached` |

**معیار پذیرش:** مراحل ۳، ۴ و ۵ بدون توقف متن. تا تأیید این مراحل، Stage 2.1 تکمیل‌شده نیست.
