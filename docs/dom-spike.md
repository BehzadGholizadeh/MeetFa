# DOM Spike — زیرنویس Google Meet

**وضعیت: تأییدشده با داده زنده — ناحیه و ساختار بلوک.**
**تأییدنشده:** برچسب‌های فارسی، دکمه Leave، دکمه CC.

- منبع: spike زنده، جلسه با زبان **Persian (Iran)**، اکتبر ۲۰۲۶ (اجرا توسط تیم، خلاصه از مدیر پروژه)
- JSON خام (`spike-fa.json` / `spike-en.json`) به Developer نرسیده؛ fixture تست از روی خلاصه بازسازی شده

## ۱. یافته‌ها
| مورد | نتیجه | وضعیت |
|---|---|---|
| ناحیه زیرنویس | `role="region"` + `aria-label="Captions"` (در جلسه فارسی هم انگلیسی) | ✅ تأیید |
| کانتینر بلوک | `div` با کلاس شبیه `nMcdL` | ✅ مشاهده |
| آواتار + نام | عنصر شامل `img` + `span` نام گوینده | ✅ تأیید |
| متن گفتار | عنصر جداگانه بعد از نام، کلاس شبیه `ygicle` | ✅ مشاهده |
| برچسب‌های فارسی («زیرنویس‌ها» و …) | در این نمونه دیده نشدند | ⏳ تأییدنشده |
| دکمه Leave / CC | گزارش نشده | ⏳ تأییدنشده |
| ثابت ماندن عنصر بلوک حین رشد | گزارش نشده | ⏳ تأییدنشده |
| حذف ابتدای متن بلوک‌های بلند | گزارش نشده | ⏳ تأییدنشده |

## ۲. تغییرات اعمال‌شده در کد
- `selectors.ts`
  - `Captions` اولویت اول؛ برچسب‌های فارسی اولویت پایین
  - جست‌وجو به ترتیب اولویت برچسب
  - افزودن `CLASS_HINTS` (`nMcdL`، `ygicle`)
- `captionParser.ts` — سه لایه:
  1. کلاس‌های مشاهده‌شده (سریع)
  2. ساختاری: `img` → ظرف نام → متن بیرون از ظرف نام (بدون وابستگی به کلاس)
  3. فرزندان مستقیم (آخرین fallback)
- نام گوینده دیگر «اولین برگ متنی» نیست؛ دقیقاً متن ظرفِ کنار `img` است

## ۳. تست‌ها (۲۱ تست parser/tracker، همه پاس — وضعیت پایان مرحله ۱)
> این عدد فقط مجموعه `tests/segmentTracker.test.ts` است. شمار کل تست‌های پروژه در README آمده
> (مرحله ۲ فایل‌های `repositories.test.ts` و `serviceWorker.test.ts` را اضافه کرده است).
- fixture بازسازی‌شده ساختار واقعی با متن فارسی ماسک‌شده
- لایه ۱ و لایه ۲ روی همان DOM خروجی یکسان می‌دهند ⇒ اگر Meet کلاس‌ها را عوض کند، parser همچنان کار می‌کند
- دکمه «Jump to bottom» وارد متن نمی‌شود
- اولویت `Captions` بر برچسب فارسی

## ۴. ریسک باقی‌مانده
- مشخص نیست «جلسه فارسی» یعنی **زبان رابط** فارسی یا **زبان زیرنویس** فارسی. اگر فقط زبان زیرنویس بوده، رفتار aria-label با رابط فارسی هنوز تست نشده (fallback فارسی برای همین نگه داشته شده)
- تشخیص ورود به جلسه به `Leave call` یا وجود ناحیه وابسته است؛ با رابط فارسی ممکن است فقط مسیر دوم (بعد از روشن کردن CC) کار کند
